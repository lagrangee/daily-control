# Extension catalog

Extensions are optional source integrations. They are not installed with the core `daily-control` Skill and are never loaded as plugins by a Daily Control application.

- [`_template/`](_template/) — contribution template.
- [`codex-computer-history/`](codex-computer-history/) — activity-history through an external Computer History Skill.
- [`mac-screen-time/`](mac-screen-time/) — device-usage reference integration for macOS Screen Time.
- [`weread/`](weread/) — reading-history through an external WeRead Skill.

Every current v0.1 entry is reference-only until its live manual acceptance is recorded.
