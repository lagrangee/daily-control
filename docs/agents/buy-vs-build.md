# Buy vs Build

Apply this protocol before adding a custom parser, serializer, standard algorithm, archive handler, secret scanner, lock, atomic-write mechanism, persistence primitive, or comparable commodity capability.

Prefer a compatible platform capability or focused, mature package. Record a lightweight Reuse Check naming the capability and candidate.

A custom implementation requires a Build Justification covering alternatives, concrete incompatibilities, the smallest custom surface, risks, proof, and deletion condition. The maintainer must explicitly accept it before implementation.

Daily Control v0.1 contains no such deterministic implementation.
