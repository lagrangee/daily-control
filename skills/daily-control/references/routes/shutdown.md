# Shutdown route

Read the Context Root `AGENTS.md`, preferences, current summary, and today's Daily record. Read the Evidence section as facts, not interpretation.

## 1. Establish the closeout

If Evidence is absent or stale, state that plainly and ask whether the user wants refresh first. Run refresh only when requested, then return here.

Ask for actual outcomes, meaningful drift, learning, unresolved items, and the next anchor. Avoid turning tool activity or time spent into an outcome claim.

Complete when the user's interpretation is clear enough to draft.

## 2. Propose and commit reflection

Draft the `## Shutdown` section, separating source-backed facts from the user's judgments. Show consequential interpretation and proposed carry-forward items for confirmation.

Write the confirmed section without changing the Open or Evidence sections. Read it back.

Complete when the durable Daily record matches the user's reflection.

## 3. Refresh current context

Update `context/now.md` only after the Daily readback. Carry forward active constraints, unresolved items, and the next anchor; remove items the durable record shows are closed. Include `Updated` and `Derived from` links.

Complete when the summary is a faithful cache and the Daily record remains canonical.
