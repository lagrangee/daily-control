# Shutdown route

Read the Context Root `AGENTS.md`, preferences, current summary, and today's Daily when it exists, including saved Evidence. Use the current conversation when available; earlier conversations on another Agent Surface are unavailable unless explicitly provided. Verify any relevant carry-forward in durable records rather than relying on the summary alone.

## 1. Draft from available context

Present a candidate closeout before requesting a general self-report. Start with the recorded direction, any supported outcomes, unresolved questions, and useful learning or carry-forward already established. Distinguish source-backed activity, attributed user statements, and uncertain Agent interpretation. Activity or time spent does not establish outcomes, intent, completion, or a trend.

Keep absent, stale, partial, unavailable, or failed Evidence visible. A gap is not proof of inactivity or failed recovery. When filling a gap could help, offer Refresh; run it only when requested under its own permissions, then return here. Missing Evidence does not prevent a bounded closeout.

Use only what helps close the day. A judgment-only, exploration, or recovery direction need not produce completed tasks or a next action. Older Daily formats remain usable without migration. Ask only for material missing interpretation or corrections that could change the closeout; when evidence is insufficient, the candidate can simply retain the confirmed direction and name what remains unknown.

Complete when the user can assess a grounded candidate and its material uncertainties without reconstructing available records.

## 2. Confirm and preserve reflection

Show the proposed `## Shutdown` content. An explicit user decision already confirms its accurate recording; ask for confirmation only for newly introduced consequential interpretation, commitments, or carry-forward. Keep hypotheses attributed and uncertain, and follow the root's write permissions. If nothing new or changed merits durable preservation, finish without a Daily or summary write.

For a durable change, create today's Daily from its template only if needed. Write only the owned Shutdown content, preserving earlier confirmed reflection, Open, Evidence, older formats, and unrelated user-authored content. Save conclusions and material uncertainty rather than a transcript. Read back the Daily before changing the summary.

Complete when the durable closeout matches the confirmed discussion and readback is complete, or the no-write outcome is explicit.

## 3. Refresh current context when needed

Only after Daily readback, update `context/now.md` if the working set changed. Carry forward confirmed constraints, unresolved questions, direction, and any useful reconsideration condition or next anchor; remove items the durable record shows are closed. Preserve the existing summary structure, `Updated`, and `Derived from` links, then read it back. An unchanged working set needs no cosmetic rewrite.

Complete when any summary update is a faithful cache of durable decisions. Report the actual outcome, including deliberate no-write completion.
