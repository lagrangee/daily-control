# Weekly Contract

Weekly reviews live at `weekly/YYYY-Www.md` and cover one explicit closed date interval according to `context/preferences.md`.

The review may synthesize Daily, Area, Project, Routine, and Evidence records. Source facts remain distinct from user interpretation. When supported by the reviewed interval, use existing review space for lessons about the control loop itself. Priority, Project, Routine, Control Policy, Controller Style, and other constraint changes require separate user confirmation and are recorded in their owner files.
